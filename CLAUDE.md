# apresentacao_flutter

Flutter app used as a slide deck for a talk (intro, Flutter & Dart, marionette, live Q&A).

## Prompt log

In the main conversation (sub-agents skip this), save each user prompt, questions included,
before any other edit or command that turn: write `prompts/prompt-NNN.md` with the next unused
zero-padded number, copying the layout of `prompts/prompt-000.md` (today's date in `Data:`),
then the prompt text verbatim. Do not commit it on your own; it is versioned for students
following the project.
